MyFolderMenu

A lightweight, high-performance Windows system tray application (.NET 8 WinForms) for quick folder and file access.

Download v1.0.0 (Win x64)

Features

  • System Tray Integration: Runs quietly in your system tray without taskbar clutter.
  • Lazy Loading Submenus: Folders and files are loaded on demand when opening submenus for instant startup.
  • Smart Organization: Subdirectories appear first, followed by files, all alphabetically sorted.
  • Real Shell Icons: Authentic Windows icons and registered handlers for every file and folder.
  • Customizable Settings: Toggle file extension visibility, choose Light, Dark, or System themes, and configure Windows startup.
  • Portable & Persistent: Configuration saved in `%APPDATA%\MyFolderMenu\folders.ini` with full export/import support.

Requirements

  • Windows 10 or Windows 11 (64-bit)
  • .NET 8 Desktop Runtime (x64)
